# Khim Stock Pick (`khim-stock2`)

ប្រព័ន្ធជំនួយការចាប់អីវ៉ាន់សម្រាប់ឃ្លាំង៖ បង្ហាញ **លេខក្បាលធ្នើរ** តម្រៀបតាមលំដាប់ជួរ និងមានប៊ូតុងធីកចំមេដៃសម្រាប់ចុចលឿនពេលកំពុងប្រញាប់។

## រចនាសម្ព័ន្ធ Files

- `index.html` — អេក្រង់ចម្បងសម្រាប់បើក Order ពិនិត្យលេខក្បាលធ្នើរ និងធីកអីវ៉ាន់ដែលចាប់រួច
- `ui/styles.css` — រចនារូបរាង ប្រអប់ពណ៌សស្អាត លេខក្បាលធ្នើរធំងាយមើល និងប៊ូតុងចំមេដៃ
- `logic/pick-sorter.js` — តម្រៀបលំដាប់តាមក្បាលធ្នើរ គាំទ្រ Import/Paste ទិន្នន័យ និងភ្ជាប់ Google Sheet CSV
- `README.md` — កំណត់ចំណាំគម្រោង និងរបៀបប្រើប្រាស់

## របៀបប្រើប្រាស់ដំណាក់កាលដំបូង

1. បើក `index.html` ដើម្បីមើលបញ្ជីអីវ៉ាន់ដែលតម្រៀបតាមលេខក្បាលធ្នើរ និងចុចធីកលើ item នីមួយៗ។
2. ប្រើផ្ទាំង **ភ្ជាប់ Export វីរាជ & Note ក្បាលធ្នើរ** ដើម្បី Paste ទិន្នន័យ / Import file ឬដាក់ Google Sheet CSV Link។
3. កត់ចំណាំចំណុចខ្វះខាត ឬមុខងារបន្ថែម ដើម្បី Update ជាបន្តបន្ទាប់។
